# CV veebileht

Lihtne HTML/CSS CV veebileht, mis on tehtud esitatud Figma maketi põhjal.

## Failid
- `index.html` – lehe sisu
- `style.css` – kujundus ja mobiilivaade
- `assets/profile-photo.jpg` – esitatud maketist lõigatud profiilipilt

## Enne esitamist
Asenda näidistekstid (`NIMI`, `Andmed`, `KOOLI NIMI`, `FIRMA NIMI` jne) enda päris CV andmetega ning vaheta profiilipilt originaali vastu, kui sul on kvaliteetsem foto.

## GitHub Pages
1. Laadi kõik projekti failid GitHubi repository juurkausta.
2. Ava repository `Settings` → `Pages`.
3. Vali `Deploy from a branch`.
4. Vali branch `main` ja kaust `/(root)`.
5. Vajuta `Save`.
6. Oota, kuni GitHub Pages lehe avaldab.
